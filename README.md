SQL_Project_Music_Store_Analysis
SQL project to analyze online music store data
This project focuses on analyzing a Music Store database using SQL to uncover valuable business insights related to customer behavior, sales performance, music genres, artists, and revenue trends.
The project demonstrates practical SQL skills used in real-world data analysis scenarios.
**Objectives**
Analyze customer purchasing behavior
Identify top-selling artists and genres
Find high-revenue customers and countries
Track sales performance and trends
Solve business-related analytical questions using SQL
**Tools & Technologies Used**
PostgreSQL
SQL
pgAdmin
**SQL Concepts Used**
Joins
Subqueries
GROUP BY & HAVING
ORDER BY & LIMIT
Window function
**Key Business Insights**
Identified top customers based on total spending
Determined the most popular music genres
Analyzed revenue contribution by country and city
Found top-performing artists and albums
Evaluated customer purchasing patterns
